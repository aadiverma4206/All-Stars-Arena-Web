# ALL STARS ARENA — Grassroots Footy Match Hub

**ALL STARS ARENA** is a premium, high-performance, single-page React web application for casual and grassroots football lovers across India. Built with **React**, **Vite**, **TailwindCSS**, **Zustand**, **Three.js / React Three Fiber**, **Framer Motion**, and **Lucide Icons**.

---

## 🚀 Quick Start Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```

---

## ✨ Features

- **3D Cinematic Football Hero**: Procedural 32-panel 3D football model with zero-gravity float physics, mouse parallax, and light/dark theme responsiveness.
- **Dynamic Rainbow Laser Border**: Multi-color running animated border line on key action buttons.
- **Interactive Pitch Finder**: Filter and search local pitches across Raipur, Bangalore, Mumbai, Pune, and Delhi with smooth scroll & highlight.
- **Interactive FAQ Accordion**: Expandable answers to common questions about games and pitches.
- **Theme Switcher**: Dark, Light, and System theme preferences with persistent local storage.
- **Official Brand Logo**: Custom geometric "A" Star emblem with typography lockup.
